S.T.A.L.K.E.R. 2 — Zone Clock PWA

Что умеет:
- показывает игровое время;
- считает игровой день;
- сохраняет состояние между запусками;
- умеет ставить часы на паузу;
- отмечает последний выброс;
- считает игровое и реальное время после выброса;
- показывает ориентировочный уровень риска следующего выброса;
- работает офлайн после первого запуска;
- устанавливается как PWA.

ВАЖНО:
PWA нельзя полноценно запустить двойным кликом по index.html, потому что Service Worker
работает только через HTTPS или localhost.

БЫСТРЫЙ ЗАПУСК НА WINDOWS:
1. Распакуйте ZIP.
2. Запустите START_LOCAL.bat.
3. Откройте в браузере:
   http://localhost:8080
4. В Chrome/Edge появится кнопка «Установить» или пункт установки в меню браузера.

РАЗМЕЩЕНИЕ В ИНТЕРНЕТЕ:
Можно загрузить содержимое папки на:
- GitHub Pages
- Netlify
- Vercel
- любой HTTPS-хостинг

После размещения PWA можно устанавливать на Windows и Android.

Примечание о расчёте времени:
В приложении сохранён практический vanilla-профиль, использованный в текущей версии часов:
примерно 60 реальных минут на игровые сутки, с разной скоростью дня и ночи.
После сна, сюжетной смены времени или паузы игры лучше выполнить ручную синхронизацию.

- кнопка принудительно запускает проверку service worker;
- отображается статус: проверка, загрузка, активация и перезапуск;
- если новая версия уже загружена, она активируется сразу;
- после успешного обновления Zone Clock автоматически перезапускается;
- добавлена обработка сообщения SKIP_WAITING;
- большая карта 16384×16384 вынесена в отдельный постоянный кэш stalker2-zone-map-16384-v1;
- при первом переходе с v61 карта по возможности копируется из старого кэша без повторного скачивания;
- при будущих обновлениях версии приложения карта не должна скачиваться заново, пока её тайлы не изменятся;
- CSV экспортируется как zone-clock-test-v62.csv;
- версия приложения обновлена до ZONE CLOCK v62.


Версия 63:
- карта берётся из настоящего исходника 16384×16384;
- исходник уменьшен ровно в 2 раза до 8192×8192;
- используется одно цельное изображение JPEG высокого качества без тайлов;
- удалены все прежние тайловые файлы карты;
- логическая система координат карты сохранена 2048×2048, поэтому измерение расстояний не изменилось;
- зум, перемещение и измерение маршрутов сохранены;
- максимальное увеличение 8× сохранено;
- карта хранится в отдельном офлайн-кэше stalker2-zone-map-8192-v1;
- версия приложения обновлена до ZONE CLOCK v63;
- CSV экспортируется как zone-clock-test-v63.csv.


Версия 64:
- ускорено перемещение большой карты 8192×8192;
- добавлена облегчённая карта 4096×4096 для активного перетаскивания и масштабирования;
- во время движения используется версия 4096×4096;
- после отпускания пальца автоматически возвращается полное качество 8192×8192;
- трансформация карты обновляется через requestAnimationFrame;
- при обычном перемещении SVG-точки маршрута больше не пересоздаются на каждом событии pointermove;
- для transform используется translate3d для более плавной композитной отрисовки;
- кнопка «ОБНОВИТЬ ПРИЛОЖЕНИЕ» в настройках сохранена;
- карта 4096×4096 добавлена в офлайн-кэш;
- CSV экспортируется как zone-clock-test-v64.csv;
- версия приложения обновлена до ZONE CLOCK v64;
- версия офлайн-кэша повышена до v64.
