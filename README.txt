S.T.A.L.K.E.R. 2 — Zone Clock PWA

Что умеет:
- показывает игровое время;
- считает игровой день;
- сохраняет состояние между запусками;
- умеет ставить часы на паузу;
- отмечает последний выброс;
- считает игровое и реальное время после выброса;
- показывает ориентировочный уровень риска следующего выброса;
- работает офлайн после первого запуска;
- устанавливается как PWA.

ВАЖНО:
PWA нельзя полноценно запустить двойным кликом по index.html, потому что Service Worker
работает только через HTTPS или localhost.

БЫСТРЫЙ ЗАПУСК НА WINDOWS:
1. Распакуйте ZIP.
2. Запустите START_LOCAL.bat.
3. Откройте в браузере:
   http://localhost:8080
4. В Chrome/Edge появится кнопка «Установить» или пункт установки в меню браузера.

РАЗМЕЩЕНИЕ В ИНТЕРНЕТЕ:
Можно загрузить содержимое папки на:
- GitHub Pages
- Netlify
- Vercel
- любой HTTPS-хостинг

После размещения PWA можно устанавливать на Windows и Android.

Примечание о расчёте времени:
В приложении сохранён практический vanilla-профиль, использованный в текущей версии часов:
примерно 60 реальных минут на игровые сутки, с разной скоростью дня и ночи.
После сна, сюжетной смены времени или паузы игры лучше выполнить ручную синхронизацию.
